# Gemini Notebook 実践リファレンス

『AI仕事最速大全 NotebookLM即戦力スキル』と付属資料を、個人利用向けの汎用リファレンスとして再構成した静的サイトです。

## GitHub Pagesで公開する

1. GitHubで `gemini-notebook-reference` というリポジトリを作成します。
2. このZIPを展開し、`index.html`、`styles.css`、`app.js`、`content.json`、`README.md` をリポジトリ直下へアップロードします。ZIPファイル自体はアップロードしません。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の Source を **Deploy from a branch** にします。
5. Branch を `main`、Folder を `/ (root)` にして保存します。
