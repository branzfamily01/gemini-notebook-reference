# Gemini Notebook 実践リファレンス

『AI仕事最速大全 NotebookLM即戦力スキル』と付属資料を、個人利用向けの汎用リファレンスとして再構成した静的サイトです。

## 収録内容

- 書籍本文を学習順に再構成した11モジュール
- 61件のプロンプト（検索・コピー・ブラウザ内保存）
- 24件のGEM
- 52件の関連記事
- 14語の用語集

## GitHub Pagesで表示する

必要なファイルは、すでにリポジトリ直下へ配置されています。

1. リポジトリの **Settings → Pages** を開きます。
2. **Build and deployment** の Source を **Deploy from a branch** にします。
3. Branch を **main**、Folder を **/ (root)** にして保存します。
4. 公開処理が完了すると、Pages画面にサイトURLが表示されます。
